# Visuels Instagram - Villa Caboua

Visuels JPEG publies automatiquement sur @villa_caboua via Make (scenario 6061814).

Contraintes Instagram :
- JPEG uniquement
- - 1080x1350 (portrait 4:5) ou 1080x1080 (carre)
  - - Largeur max 1440, poids max 8 Mo
   
    - Nommage : identique au fichier Google Drive, espaces remplaces par des tirets, extension .jpg
    - Exemple : "pub 17.png" sur Drive donne pub-17.jpg ici
